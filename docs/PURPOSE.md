# Original purpose

Build a **multi-agent opportunity pipeline** for Aether Applied (BMS / building-energy business development).

Take a company or lead from raw signal → verified evidence → qualification → technical feasibility → funding/partnership match → **human review**, without agents inventing facts or treating each other’s guesses as truth.

**Notion** = system of record (queue, knowledge base, review).  
**Python agents** = workers (local, GitHub Actions, or AWS ECS).  
**Humans** = approve anything that matters for sales or applications.

See also the top of [`README.md`](../README.md) and [`notion-agents-library.md`](notion-agents-library.md) for Library vs registry.
